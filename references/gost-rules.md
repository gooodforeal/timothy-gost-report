# Правила оформления по ГОСТ

Отчёты (лабораторные, практики, курсовые, рефераты, НИР) оформляются по ГОСТ на
отчёты с поправками из методички вуза. **Методичка всегда главнее этой таблицы.**
Если в ней другие поля, кегль или нумерация, перенесите отличия в
`plain/style.json`.

## Что делает скрипт (значения по умолчанию)

| Параметр | Значение | Ключ в `style.json` |
|---|---|---|
| Формат листа | A4 (210×297 мм), книжная ориентация | — |
| Поля | левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм | `margin_left_mm`, `margin_right_mm`, `margin_top_mm`, `margin_bottom_mm` |
| Шрифт текста | Times New Roman, чёрный | `font_name` |
| Кегль текста | 14 пт | `font_size_pt` |
| Межстрочный интервал | 1,5 | `line_spacing` |
| Абзацный отступ | 1,25 см, одинаковый во всём тексте | `first_line_indent_cm` |
| Выравнивание текста | по ширине | — |
| Полужирный | только заголовки | — |
| Заголовки (все уровни, включая Введение, Заключение, Приложения, Содержание) | полужирные, 14 пт, **по левому краю с абзацного отступа 1,25 см**, с прописной буквы, **не капсом**, без точки в конце; **интервал перед и после — 0 пт** | — |
| Разделы | «1 Название», «1.1 Название», «1.1.1 Название»; номер без точки | — |
| Структурные элементы | «Введение», «Заключение», «Список использованных источников» — без номера | — |
| Новая страница | **каждый заголовок первого уровня** (`#`) начинается с новой страницы: Введение, разделы, Заключение, Список источников, приложения. Не настраивается | — |
| Перечисления | «– пункт;» с абзацного отступа; нумерованные «1)», вложенные «а)» | — |
| Рисунки | по центру; подпись под рисунком по центру: «Рисунок 1 — Название», без точки | — |
| Таблицы | подпись над таблицей слева без отступа: «Таблица 1 — Название»; шапка повторяется на каждой странице; текст 12 пт, интервал 1 | `table_font_size_pt` |
| Формулы | по центру, номер «(1)» у правого края; ссылка в тексте «по формуле (1)» | — |
| Листинги | подпись над кодом слева: «Листинг 1 — Название»; **Consolas 12 пт**, интервал 1, без абзацного отступа | `listing_font_name`, `listing_font_size_pt`, `listing_line_spacing` |
| Нумерация рисунков, таблиц, формул, листингов | сквозная (1, 2, 3) или в пределах раздела (2.1, 2.2) | `caption_numbering`: `"continuous"` / `"by_section"` |
| Приложения | «Приложение А. Название», с новой страницы; буквы без Ё, З, Й, О, Ч, Ь, Ы, Ъ; рисунки внутри — «Рисунок А.1» | — |
| Список источников | нумерация «1.» в порядке первой ссылки в тексте; ссылки в тексте в квадратных скобках [1] | — |
| Содержание | генерируется автоматически (поле Word), заголовок «Содержание» | `has_table_of_contents` |
| Номера страниц | арабские цифры внизу по центру, без точки, на каждой странице | `first_page_number` |
| Титульный лист | **не генерируется** — его делают отдельно | — |

Титульный лист обычно вставляется перед отчётом и считается первой страницей.
Тогда в `style.json` ставится `"first_page_number": 2`, и нумерация начинается
с 2. Если титульник прикладывать не будут, оставьте значение по умолчанию 1.

## Правила, которые выполняет агент при написании текста

Смысл скрипт проверить не может, за ним следит агент:

- **Ссылки на все рисунки, таблицы, формулы, листинги и приложения есть в тексте**
  и стоят *до* самого объекта: «…показана на рисунке [@fig:x]», «…в таблице [@tbl:x]».
- Рисунок и таблица стоят после первого упоминания, не раньше.
- После формулы символы поясняются: «где *S* – стоимость, руб.;». Пояснение
  начинается со слова «где» без двоеточия.
- Перед перечислением ставится двоеточие, пункты пишутся со строчной буквы, в
  конце пункта «;», в последнем «.». Если пункты — полные предложения, тогда с
  прописной буквы и с точкой.
- Раздела с одним подразделом не бывает: если есть 1.1, должен быть и 1.2.
- Между заголовком раздела и заголовком подраздела — хотя бы абзац текста.
- Заголовки пишутся без точки в конце, без переносов и без сокращений.
- Числа с единицами пишутся цифрами: «5 мс», «10 000 заказов».
- Кавычки «ёлочки», тире «–» с пробелами, не дефис.
- Сокращение расшифровывается при первом упоминании: «система управления базами
  данных (СУБД)». Если сокращений много, добавьте раздел «Перечень сокращений и
  обозначений».
- Ссылки на источники пишутся как `[1]`, `[2, с. 15]`, `[3–5]`. Порядок в списке —
  по первому упоминанию.

## Библиографическая запись

Примеры записей для раздела «Список использованных источников»:

```
1. Иванов, И. И. Базы данных : учебное пособие / И. И. Иванов. – Москва : Юрайт, 2023. – 320 с. – ISBN 978-5-534-00000-0.
2. Петров, П. П. Индексы в PostgreSQL / П. П. Петров, С. С. Сидоров // Программная инженерия. – 2024. – Т. 15, № 3. – С. 112–120.
3. PostgreSQL 16 Documentation : [сайт]. – URL: https://www.postgresql.org/docs/16/ (дата обращения: 30.10.2026).
```

Это шаблоны формата, а не настоящие источники. Не выдумывайте источники:
используйте только то, что дал пользователь, что есть в методичке, или то, что
агент реально нашёл и проверил (ссылка открывается, книга существует).

## Структура типичных отчётов

Титульный лист во всех случаях делается отдельно и в `plain/` не входит.

**Курсовая / отчёт о НИР:** реферат (по требованию), содержание, термины и
определения, перечень сокращений, введение, основная часть (разделы 1, 2, 3…),
заключение, список использованных источников, приложения. Обязательны
содержание, введение, основная часть и заключение, остальное — по необходимости.

**Лабораторная работа (типичная методичка):** содержание (часто не нужно —
`"has_table_of_contents": false`), цель работы, задание или вариант, ход работы
(теория, реализация, результаты), выводы, список источников, приложения с кодом.

**Отчёт по практике:** содержание, введение, разделы по заданию, заключение,
список источников, приложения.

**Реферат:** содержание, введение, 2–3 раздела, заключение, список источников
(8–15 источников).

## Частые отличия в методичках

Сверьтесь с методичкой. Если что-то отличается, задайте это в `style.json`:

- правое поле 10 мм вместо 15 мм → `"margin_right_mm": 10`;
- кегль 12 пт → `"font_size_pt": 12`;
- нумерация рисунков в пределах раздела → `"caption_numbering": "by_section"`;
- листинги кеглем 10 → `"listing_font_size_pt": 10`;
- без содержания → `"has_table_of_contents": false`;
- титульный лист будет вставлен отдельно → `"first_page_number": 2`.
