# Введение

В лабораторной работе разрабатывается небольшой сервис учета заказов для учебного интернет-магазина. Сервис принимает заказы через REST API и хранит их в PostgreSQL.

Цель работы – спроектировать API и схему данных так, чтобы ими можно было пользоваться без доработок на следующем этапе курса. Для этого нужно было:

- описать сущности предметной области;
- выбрать формат запросов и ответов;
- проверить производительность на тестовых данных.
